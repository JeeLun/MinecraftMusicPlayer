# 在线音乐播放器

把五线谱 txt 放到网页上直接听。用 GitHub Pages 部署，零成本。

## 目录结构

```
仓库根/
├── index.html              ← web/music-player/index.html 复制过去
└── music/
    ├── index.json          ← 曲目清单(推荐)
    ├── 我的谱子.txt
    ├── 另一首.txt
    └── sounds/
        └── harp.ogg        ← 可选, 音符盒音色
```

## 部署步骤

1. 建一个仓库（比如 `my-music`），把上面的结构推上去
2. 仓库 **Settings → Pages** → Source 选 `main` 分支 `/ (root)` → 保存
3. 等一两分钟，访问 `https://<你的用户名>.github.io/my-music/`

## 曲目清单 `music/index.json`

```json
{
  "files": ["第一首.txt", "第二首.txt"]
}
```

- 有清单时按清单列出（**推荐**，不受 API 限流影响）
- 没有清单时会尝试用 GitHub API 列目录（每小时 60 次限流，且要求仓库公开）

## 本地文件

页面上的「＋ 上传乐谱」可以直接选本地 `.txt`，不上传服务器，纯浏览器内解析播放。

## 音色

| 情况 | 效果 |
|---|---|
| `music/sounds/harp.ogg` 存在 | 用真实音符盒音色，按音高变调 |
| 不存在 | 用三角波合成音（能听出旋律，但不像音符盒） |

获取 `harp.ogg`：从自己的 Minecraft 客户端里找
```
.minecraft/assets/objects/... (需要按 hash 找)
```
或者从 `assets/minecraft/sounds/block/note_block/harp.ogg` 提取后放进去。

> 注意：Minecraft 音效有版权，公开仓库放音频可能不合适；不想公开就只上传 txt，让别人用合成音。

## 支持的乐谱格式

与 mod 里的解析器对齐：

| 记号 | 含义 |
|---|---|
| `bpm=120` | 速度（每个顶层块可重新指定） |
| `G=3♯` / `F=1♭` | 高音/低音谱号调号 |
| `G: { 4:8 5:8 }` | 高音谱子块；`F:` 低音；`D:` 鼓；`V:` 歌词 |
| `4:8` | 音高 `4`，八分音符 |
| `♯4:16` / `♭3:8` / `♮4:4` | 临时升/降/还原 |
| `4:8.` | 附点 |
| **`4:8=`** | **长音**（每个 tick 重触发，用来做延音） |
| `0:4` | 休止 |
| `4:8,6:8,8:8` | 和弦（逗号并列，同时发音） |

音高位置：`0` 是中央 C 所在线上，正数往高音走，负数往低音走，支持 `.5`（如 `3.5`）。

## 已知限制

- 不做小节线/拍号校验，写错就是写错
- 同小节临时升降还原（`♮`）只做了部分处理
- 鼓（`D:` 块）目前按普通音高播放
- 长音会把事件数量放大（每 tick 一个），超长曲目可能有点吃 CPU

## 手动测试

打开页面，F12 看控制台：

```js
// 解析一首谱子看看

```
